## Checkpoint 1: settings, geometry and compatibility

- Per-feature `Prediction = {Enabled, Auto, Value}` replaces the top-level table.
  Auto ignores Value and uses the larger smoothed network/data RTT estimate plus
  bounded sample age. It is an estimate, not a fitted server latency model. No
  bullet speed is invented from tracer animation; travel time is currently zero.
- Removed Aim Assist's Y-axis setting. Silent Auto no longer adds gravity solely
  because a remote humanoid reports Air. A separate GroundShotCheck uses a floor
  ray and rig/point geometry, rather than a constant upward offset.
- Recognize AMMO and Ammo, and the observed Handle.Flare muzzle attachment.
- Closest selects standard body parts rather than helper parts (the previous live
  capture selected a child named `fix`). Point smoothing stays inside current bounds.
- Triggerbot prioritizes a fresh cursor ray and its actual hit surface, instead of
  stale Mouse.Target and a different, potentially obstructed body-part center.
- Cached velocity fits; bounded 60 Hz aiming/overlay work; frame-based camera
  smoothing; optional fractional mouse smoothing. Bounded diagnostic traces expose
  raw/sample velocity, selection, Y adjustment and submitted MOUSE coordinates.

## Checkpoint 2: live lifecycle finding and additional regressions

The new full bundle loaded in REAL with no runtime errors. Idle aiming work
averaged ~0.067 ms/update in its first sample (maximum 0.366 ms); this is not a
combat benchmark. REAL's static analyzer still reports dynamic-table inference
errors inherited from this portable Lua design; it is not a clean lint pass.

Live observation after respawn found a stale muzzle origin from the previous
weapon/corpse while no weapon was equipped. Muzzle attachments now require ancestry
under the current equipped tool, and character changes clear the attachment.
Ground correction only limits downward lead and never raises the point above its
unpredicted height. This avoids interpreting an animated/crouched rig as an upward
correction request.

Added regressions for AMMO observation/empty firing prevention, Flare origin,
unequip cleanup, Auto ignoring manual Value/JumpOffset, no invented gravity for
zero-Y Air, rig-derived landing limits, bounded traces, and fresh cursor ray
precedence over stale Mouse.Target. Both suites pass.

First five live shot attempts found no unobstructed eligible target and fired no
shots. The avatar was also knocked/dead during parts of the live session. Those
attempts establish no hit rate. Wall checks were retained. Normal pathfinding was
used to move toward available targets for subsequent testing.

The logo container increases from 1800 to 2100 pixels. Readiness now polls IsLoaded
instead of blocking the worker in PreloadAsync. The live cache contained the PNG
and Ogg at their expected byte lengths; actual improved intro rendering is still
pending. Session-once behavior and no exposed intro settings remain unchanged.
